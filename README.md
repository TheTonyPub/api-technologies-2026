# API-технологии — 2026

## Семинар 1. Проектирование взаимодействия сервисов

Совместно разберём архитектурный кейс, разделимся на команды и случайно распределим три семестровых проекта. Начнём проектирование назначенного кейса на занятии.

## Домашнее задание 1. Архитектура командного проекта

Завершите начатую на семинаре архитектуру одного назначенного команде кейса:

1. Выделите внешних потребителей системы.
2. Постройте контекстную диаграмму C4, уровень 1.
3. Постройте контейнерную диаграмму C4, уровень 2.
4. Выберите протоколы взаимодействия сервисов и внешних потребителей.
5. Выберите базы данных и кратко объясните решения по протоколам и хранению.

Условия кейсов выдаёт преподаватель. Реализация системы продолжится в течение семестра.

## Сдача

Работайте одной командой в приватном fork или репозитории, продолжая эту учебную ветку. Добавьте состав команды, назначенный кейс, диаграммы и пояснения. Диаграммы должны быть доступны для просмотра. Передайте ссылку на PR/MR с результатами и итоговый commit.

Семинар и ДЗ выполняются в одной рабочей линии: [seminar/01-api-scenarios](https://github.com/TheTonyPub/api-technologies-2026/tree/seminar/01-api-scenarios).
